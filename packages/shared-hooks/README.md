# @ataqu/shared-hooks

Reusable React hooks.

- `useWebSocket` – WebSocket management with auto-reconnect.
- `useSSE` – Server-Sent Events with fallback polling.
- `useIdempotency` – generates and manages Idempotency-Key headers.
- `useOptimistic` – optimistic updates with rollback.
- `useOnboard` – controls onboarding tour state.
- `useDebounce`, `useClickOutside`, `useHotkeys`, etc.
